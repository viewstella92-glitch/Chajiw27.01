# 拆句 江湖 — ตำรับยุทธ์แยกประโยคจีน (Vercel version)

เว็บแยกประโยคภาษาจีนธีมยุทธภพ ใช้ **Groq** (แยกคำ/แยกส่วนประกอบ/ฝึกแต่งประโยค) + **Gemini** (ทายลายมือ) ทั้งคู่ฟรี ไม่ต้องผูกบัตรเครดิต

## ฟีเจอร์
- แยกคำ + พินอิน + วรรณยุกต์ + คำแปล + ไวยากรณ์ + ระดับ HSK โดยประมาณ
- แยกส่วนประกอบตัวอักษร + คำอื่นที่มีตัวอักษรนี้อยู่
- วาดตัวจีน + ทายลายมือ (Gemini vision)
- บันทึกคำศัพท์ + เล่นแฟลชการ์ด (พร้อมระบบทบทวนแบบ spaced repetition)
- **แดชบอร์ด**: ขั้นภูมิ (境界) ตามจำนวนคำที่สะสม, สถิติการเรียน, ปฏิทินต่อเนื่อง, คำที่ครบกำหนดทบทวน, สถิติรูปแบบไวยากรณ์
- **ควิซ**: สุ่มคำถามจากคำศัพท์ที่บันทึกไว้ (สร้างฝั่ง client ไม่เปลืองโควต้า API)
- **ฝึกแต่งประโยค**: สุ่มคำจากคลังคำศัพท์ แต่งประโยคเอง แล้วให้ AI ตรวจและแก้ไขให้

## รันทดสอบในเครื่องตัวเอง

1. ติดตั้ง dependencies:
   ```
   npm install
   ```
2. คัดลอก `.env.local.example` เป็น `.env.local` แล้วใส่ API key ของคุณ:
   ```
   GEMINI_API_KEY=your_key_here
   GROQ_API_KEY=your_groq_key_here
   ```
   - Gemini key ขอได้ฟรีที่ https://aistudio.google.com/apikey (จำเป็น — ใช้เฉพาะฟีเจอร์ทายลายมือที่ต้องอ่านภาพ)
   - Groq key ขอได้ฟรีที่ https://console.groq.com/keys (จำเป็น — ใช้กับฟีเจอร์แยกคำ/แยกส่วนประกอบทั้งหมด ไม่ต้องผูกบัตรเครดิต)
3. รัน:
   ```
   npm run dev
   ```
   เปิด http://localhost:3000

## Deploy ขึ้น Vercel

1. Push โค้ดโฟลเดอร์นี้ขึ้น GitHub repo ใหม่
2. เข้า https://vercel.com → "New Project" → เลือก repo นี้
3. ก่อนกด Deploy ให้ไปที่ **Environment Variables** แล้วเพิ่ม:
   - Key: `GEMINI_API_KEY` → Value: (Gemini API key ของคุณ — ใช้กับทายลายมือ)
   - Key: `GROQ_API_KEY` → Value: (Groq API key ของคุณ — ใช้กับแยกคำ/แยกส่วนประกอบ จำเป็นต้องใส่)
4. กด Deploy รอสักครู่ ก็จะได้ URL ของเว็บไซต์ตัวเอง (เช่น `chaiju.vercel.app`)

**สำคัญ:** ห้าม commit ไฟล์ `.env.local` ขึ้น GitHub เด็ดขาด (มี `.gitignore` กันไว้ให้แล้ว) — key ต้องตั้งผ่านหน้า Environment Variables ของ Vercel เท่านั้น เพื่อไม่ให้ใครเห็น key ของคุณ

## โครงสร้างไฟล์

- `app/page.js` — หน้าเว็บหลัก (UI ทั้งหมด)
- `app/api/segment/route.js` — เรียก Gemini เพื่อแยกคำ+วิเคราะห์ไวยากรณ์
- `app/api/breakdown/route.js` — เรียก Gemini เพื่อแยกส่วนประกอบตัวอักษร
- `app/api/related/route.js` — เรียก Gemini เพื่อหาคำอื่นที่มีตัวอักษรนี้เป็นส่วนประกอบ
- `app/api/recognize/route.js` — เรียก Gemini (vision) เพื่อทายตัวอักษรจากลายมือ

ทั้ง 4 ไฟล์ API route นี้รันบนฝั่งเซิร์ฟเวอร์ (ไม่ใช่ฝั่งเบราว์เซอร์) เพื่อไม่ให้ API key รั่วไหลออกไปสู่ผู้ใช้งาน

## ติดหน้าจอหลัก (PWA)

เว็บนี้มี `manifest.json` และไอคอน 拆 ในตัวแล้ว พอ deploy เสร็จ เปิดเว็บผ่าน Safari (iOS) หรือ Chrome (Android) แล้วกด "เพิ่มไปที่หน้าจอโฮม" จะได้ไอคอนแอปจริงๆ ไม่ใช่ไอคอนเบราว์เซอร์เปล่าๆ

## หมายเหตุ

- คำศัพท์ที่บันทึกไว้เก็บด้วย `localStorage` ของเบราว์เซอร์ — **ผูกกับเบราว์เซอร์/อุปกรณ์นั้นๆ** ไม่ sync ข้ามเครื่องอัตโนมัติ
- **แยกคำ/แยกส่วนประกอบ**: ใช้ **Groq เท่านั้น** (ลอง 2 โมเดลตามลำดับถ้าตัวแรกโควต้าเต็ม) — ไม่แตะโควต้า Gemini เลย
- **ทายลายมือ**: ใช้ **Gemini เท่านั้น** เพราะต้องอ่านภาพ ซึ่ง Groq ไม่รองรับ — โควต้า Gemini ทั้งหมดจึงเหลือไว้สำหรับฟีเจอร์นี้อย่างเดียว
- ผลลัพธ์การแยกคำและแยกส่วนประกอบจะถูก cache ไว้ใน `localStorage` ของเบราว์เซอร์ด้วย ถ้าวิเคราะห์ประโยค/คำเดิมซ้ำจะไม่เรียก API ใหม่
